## Proyecto
Aplicación web construida con Astro.

## Stack
- Astro
- JavaScript / TypeScript
- Node.js
- Docker
- Cloudflare
- tailwindcss
- MySQL

## Reglas
- Responder en español.
- Ser breve y directo.
- Antes de modificar código, explicar el plan.
- Priorizar seguridad, simplicidad y bajo consumo de tokens.
- No hacer cambios amplios sin confirmación.
- Mantener compatibilidad con la estructura y convenciones de Astro.

## Flujo
1. Analizar la tarea.
2. Proponer solución corta.
3. Implementar solo lo necesario.
4. Resumir cambios al final.

## Comandos
- Instalar: `npm install`
- Desarrollo: `npm run dev`
- Build: `npm run build`
- Preview: `npm run preview`

## Convenciones
- Usar componentes y rutas de Astro de forma idiomática.
- Evitar dependencias innecesarias.
- Mantener componentes pequeños y claros.
- No duplicar lógica.
- Validar entradas y manejar errores.
- Favorecer rendimiento y carga rápida.

## Notas
- Usar Sonnet por defecto para desarrollo.
- Si falta contexto, preguntar antes de asumir.
- Si el cambio afecta varias páginas o componentes, confirmar primero.
